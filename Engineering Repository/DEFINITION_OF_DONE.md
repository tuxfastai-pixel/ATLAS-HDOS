# Definition of Done

A sprint item is done only when all relevant items below are true.

## Product

- The work supports an approved sprint goal or documented product need.
- Acceptance criteria are met.
- User-facing behavior is coherent and complete for the agreed scope.

## Engineering

- Code follows the coding standards.
- Architecture remains understandable and documented.
- PEOS boundaries are respected.
- No known production-blocking errors are left unresolved.

## Testing

- Relevant automated tests are added or updated.
- Manual verification is documented when automation is not practical.
- Critical workflows are checked for regressions.

## Security and AI

- Input, permissions, secrets, and data flows are reviewed.
- AI behavior follows the project AI rules.
- Sensitive data handling is documented where applicable.

## Documentation

- Related docs, ADRs, release notes, or backlog items are updated.
- Any new assumptions or follow-up work are recorded.
