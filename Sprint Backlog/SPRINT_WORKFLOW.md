# Sprint Workflow

## Sprint Inputs

- Sprint goal
- Prioritized backlog items
- Acceptance criteria
- Definition of Done
- Known dependencies
- Known risks

## Sprint Rhythm

1. Define the sprint goal.
2. Select backlog items that support the goal.
3. Confirm acceptance criteria for each item.
4. Identify PEOS, AI, database, API, design, and security impacts.
5. Implement in small reviewable increments.
6. Verify through tests and manual checks.
7. Update documentation and release notes.
