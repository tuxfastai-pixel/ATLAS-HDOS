# PEOS Dependency Model

PEOS is the shared platform for the Pinnacle Sentle Group Engineering ecosystem. Atlas HDOS should depend on PEOS intentionally and visibly.

## PEOS Owns

- Shared identity and access foundations
- Shared platform services
- Shared integration contracts
- Cross-product AI infrastructure
- Common telemetry and operational patterns
- Platform-level security controls

## Atlas Owns

- Atlas-specific product experiences
- Atlas learning and capability workflows
- Atlas mission, companion, and human development logic
- Atlas-specific domain models
- Atlas release priorities and user-facing acceptance criteria

## Integration Rules

- Shared capabilities should be proposed for PEOS instead of duplicated in Atlas.
- Atlas-specific needs can start locally only when there is a clear reason.
- Any local implementation that may become shared must be documented.
- PEOS contracts should be versioned before production use.
